## 📖 About The Project

The **Travel Guide Website** is a web-based tourism platform developed as part of the **BECS 31233 – Web and Internet Technologies** module in **3rd Year Semester 1**.

This project was created to help users explore countries, discover tourist attractions, search destinations, and read travel-related blogs and tips through a modern and user-friendly interface.

---

# ✨ Features

✅ Explore countries and destinations  
✅ Search tourist places  
✅ View detailed place information  
✅ Browse top-rated attractions  
✅ Read travel blogs and travel tips  
✅ Admin panel for content management  
✅ Responsive and clean user interface

# 📂 Project Modules

## 🌍 Countries Module
- Display countries in card format
- View places related to each country
- Fetch country data from database

## 🗺️ Places Module
- Display tourist attractions
- Category filtering system
- Top-rated places section

## 🔍 Search Module
- Search destinations by name
- Filter search results dynamically

## 📄 Place Details Module
- Full place information
- Ratings, categories, images, and descriptions

## 📝 Blog & Travel Tips
- Travel blog posts
- Travel guidance and tips

## 🧑‍💼 Admin Panel
- Secure admin login
- Add/Edit/Delete countries
- Add/Edit/Delete places
- Image upload management
