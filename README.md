🌍 Travel Guide Website

Welcome to the Travel Guide Website project — a dynamic and user-friendly tourism platform developed as part of the BECS 31233 – Web and Internet Technologies module in 3rd Year, Semester 1.

This project was designed and developed by our team to provide travelers with an engaging platform to explore countries, discover tourist attractions, search destinations, and read travel blogs and tips.

✨ Project Overview

The Travel Guide Website allows users to:

🌎 Explore different countries
🗺️ Discover famous tourist destinations
🔍 Search places easily
⭐ View top-ranked attractions
📝 Read travel blogs and travel tips
🧑‍💼 Manage content through an admin panel

The system is built using modern web technologies and follows a clean, responsive, and user-friendly design.

📌 Installation Guide
Clone the repository
Move the project folder into htdocs
Start Apache and MySQL using XAMPP
Import the database into phpMyAdmin
Run the project in browser:
http://localhost/travel-guide
