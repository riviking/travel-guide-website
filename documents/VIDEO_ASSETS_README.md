# Hero Video Asset

Add the home page hero video here with one of these filenames:

```text
travel-hero.mp4
travel-hero.webm
```

The home page already includes a video background in `index.php`. If no video file is available, it falls back to `assets/images/backgrounds/home.jpg`.

Recommended video settings:

- Short travel clip, 8 to 20 seconds
- Muted background video
- Landscape format
- Optimized file size for faster loading
